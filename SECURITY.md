# Security Policy

## Supported Versions

Only the latest release receives security fixes.

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues, discussions or pull requests.

Report them privately through GitHub instead:

1. Open the [Security tab](https://github.com/SvenTUM/eredmine-agent-gateway/security) of this repository.
2. Click **Report a vulnerability** and describe the issue.

Please include:

- the affected version or commit,
- the steps to reproduce the issue,
- the impact you expect (for example, exposure of API keys or unintended write access to Easy8).

## What to Expect

This project is maintained in spare time. I aim to acknowledge reports within 30 days and will keep you informed about the fix. Once a fix is released, the vulnerability is published as a GitHub security advisory, crediting you if you wish.

## Scope

In scope are this package, its CLI, its MCP server and the Open WebUI tool. Vulnerabilities in Easy8, Redmine, Open WebUI or other dependencies should be reported to their maintainers.
